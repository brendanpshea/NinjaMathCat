Privacy

Whiskerblade, a math game for kindergarten to 6th grade by Brendan Shea, collects nothing about the children who play it, or about anyone else.

What the game keeps

For each player on a device, the game saves a name (whatever is typed in, which needn't be a real name), a hero, a grade, the levels played and the stars won, treasures, and how well each kind of question is going. It keeps these on the device only, in the browser's storage (in the Android app, the storage of the browser the app runs in). They are never sent anywhere.

Removing a player from the game deletes theirs. Clearing the browser's data for the game deletes everyone's.

What is sent

Nothing the game keeps. There are no accounts, ads, analytics, trackers or purchases. A progress code is made on the device and goes only where someone copies it. A teacher's class view reads the codes pasted into it, on the teacher's own device, and keeps them there.

Others involved

  • The game is a website served by GitHub Pages. Like any web server, GitHub's sees the internet address of each device that asks for the game's files, and may keep it for a while for security. GitHub's privacy statement, at docs.github.com, says how.
  • The Android app opens the game in the phone's browser, usually Chrome, whose own privacy policy covers the browser.
  • "Read to me" uses the device's own voices. On some devices those voices come from an online service run by the maker of the device or browser, which then receives the words being read, and nothing about who is playing.

Children

Whiskerblade is made for children. Because it collects no personal information, there is none to share, sell or delete on our side, and nothing for a parent to request.

Questions and changes

Questions are welcome on the project's page, github.com/brendanpshea/NinjaMathCat, under Issues. If this policy ever changes, the new one will be here, with its date.
