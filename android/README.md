# The Android app

`twa-manifest.json` is the Android app's settings, for
[Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap). Everything
else Bubblewrap makes here is left out of git, and so is the signing key.
How to build it, and get it onto Google Play: [docs/ANDROID.md](../docs/ANDROID.md).
